# 3.26.102315 · 现代玻璃界面

## 更新内容

- 更新默认浅色与深色配色，新增薄荷汽水、蜜桃橘子、莓果气泡、鸢尾电光、霓虹莓夜、极光薄荷夜六套主题；主题列表加入色板预览。
- 顶栏、底栏与阅读菜单采用玻璃材质。Android 13 及以上支持背景折射、边缘色散；Android 12 使用模糊回退，更早系统、墨水屏与省电模式使用静态背景。
- 默认浅色背景采用简约艺术图，默认书籍封面采用彩色几何设计；已有自定义背景和真实封面保持优先。
- 更新实心圆润图标，底栏选中态完整包住图标与文字，减轻底栏投影，并将“我的”改为无外圈人像。

## 安装说明

本仓库首次独立签名发布，应用包名为 `io.legado.app.release`。签名与上游原版或测试版不同；如果系统提示签名不兼容，请先在旧应用中备份数据，再卸载旧版并安装、恢复备份。请勿直接卸载尚未备份的旧应用。

## 构建与维护

- 使用 JDK 17、Android SDK 36 构建 `:app:assembleAppRelease`；Release 启用代码混淆和资源压缩。
- 版本可通过 `ORG_GRADLE_PROJECT_RELEASE_VERSION=3.26.102315` 固定，避免不同构建时刻产生不同版本名。
- 正式签名保存在发布机器的 `release/signing/`，该目录已被 Git 忽略；后续升级必须复用同一密钥。应单独保管该目录，不上传到仓库或 Releases。
- UI 验证和前后对比见 [底栏优化记录](../design/navbar-refinement.md)。已知 Android Lint 仍报告项目原有的 14 项错误，本轮界面修改没有新增错误。

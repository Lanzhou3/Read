# 阅读 3.26.102323

## 更新内容

- 修复悬浮导航下方内容提前消失、玻璃取样未随滚动更新的问题。
- 重新设计阅读外观、字体排版、边距和页面信息设置，增加直观预览与带值调节。
- 内置开源霞鹜文楷，提供字体预览、授权说明和阅读样式备份支持。
- 更新设置卡片与多彩图标，按阅读、书源、备份连接和高级工具整理入口。
- 新增清晰的添加书籍/书源选择面板，改进发现、搜索和书源空状态及输入错误提示。
- 重做朗读、睡眠定时和自动翻页控制，更新目录悬浮操作栏并修复横屏底部遮挡。
- 优化书籍详情、订阅图标容器、远程书库表单及常用菜单。

## 安装

下载 `read-3.26.102323-release.apk`。包名为 `io.legado.app.release`，继续使用本仓库上一版的签名，可覆盖安装上一版 Release。

保留现有阅读配置；内置字体可在“阅读外观 → 字体排版 → 阅读字体”中选择。与上游原版或其他签名版本之间迁移，请先使用应用内备份和恢复功能保存数据。

## 已知限制

- 完整 Android Lint 仍有 14 条既有错误，当前改动未新增错误。
- 专业规则编辑器、部分系统弹出窗口和媒体内部框架尚未完成后续整理。
- 本轮主要验证模拟器中的界面与常用流程，真实网络书源、远程存储和后台音频仍需在实际使用环境验证。

## 验证

六套强调色与页面背景的静态对比度分别为 4.83、4.70、5.58、5.81、8.84、12.45。玻璃导航继续使用原有最差背景范围校正；上述比值不代表每一种半透明叠加状态均具有相同比值。

JSON 名称无重复，颜色格式有效。预览把有效的透明颜色转为不透明色展示，并对无效的旧导入配置提供回退。
